### Register-Level Programming
- [ ] Understand memory-mapped I/O — accessing peripherals via `volatile` pointers
- [ ] Read datasheets: register maps, bit fields, clock configuration registers
- [ ] Write a bare-metal GPIO driver using only registers (no HAL)
- [ ] Write a bare-metal UART driver using only the reference manual
- [ ] Write a bare-metal SPI/I2C driver from registers
- [ ] Practice bit manipulation: set, clear, toggle, mask, shift operations
